# Потокова генерація (SSE): концепція

## Ідея
Claude і так викликає інструмент `submit_test_suite`; Anthropic API вміє стримити його аргументи
шматками часткового JSON (`content_block_delta` → `input_json_delta`). `CaseExtractor`
(`app/services/stream_parser.py`) збирає ці шматки й віддає кожен тест-кейс одразу, щойно
закрилася його `}`. Кейс валідується Pydantic, отримує серверний ID і йде клієнту.

```
Claude --partial JSON--> AIService.stream_test_suite --CaseExtractor--> TestCase
        --StreamEvent--> POST /api/generate-stream --SSE--> браузер
```

## Контракт `POST /api/generate-stream`
Тіло запиту - те саме, що й у `/api/generate`. Відповідь: `text/event-stream`.

| event   | data                                    | коли                                    |
|---------|-----------------------------------------|-----------------------------------------|
| `case`  | один `TestCase` (ID вже `TC-00N`)       | кейс повністю отримано й провалідовано  |
| `done`  | повний `TestSuite` (summary, припущення)| потік завершено; потрібен для експорту  |
| `error` | `{detail, status}`                      | збій; після нього потік закривається    |

## Клієнт (fetch + ReadableStream)
`EventSource` вміє лише GET, тому для POST читаємо потік вручну:

```js
const r = await fetch('/api/generate-stream', {method: 'POST',
  headers: {'Content-Type': 'application/json'}, body: JSON.stringify(payload)});
const reader = r.body.pipeThrough(new TextDecoderStream()).getReader();
let buf = '';
for (;;) {
  const {value, done} = await reader.read();
  if (done) break;
  buf += value;
  let i;
  while ((i = buf.indexOf('\n\n')) >= 0) {
    const frame = buf.slice(0, i); buf = buf.slice(i + 2);
    const event = /^event: (.*)$/m.exec(frame)?.[1];
    const data = JSON.parse(/^data: (.*)$/m.exec(frame)[1]);
    if (event === 'case') appendCase(data);          // додати рядок до списку
    else if (event === 'done') { currentSuite = data; enableExport(); }
    else if (event === 'error') showError(data.detail);
  }
}
```
Це спрощений приклад. Робоча версія в `app/templates/index.html` додатково:
- підтримує `\r\n`, багаторядкові `data:` і коментарі `: ping`;
- до початку потоку перевіряє `response.ok` (помилки 422/500 приходять звичайним JSON);
- вважає потік, закритий без `done` і `error`, обривом з'єднання;
- перериває запит, якщо 90 секунд не прийшло жодного байта, і дає кнопку «Зупинити генерацію» (`AbortController`).

## Поведінка інтерфейсу

| Ситуація | Що бачить користувач |
|---|---|
| Прийшов `case` | кейс плавно додається в кінець списку, лічильник «Отримано кейсів: N» зростає |
| Триває генерація | експорт заблоковано («стане доступний після завершення генерації»), видно кнопку «Зупинити генерацію» |
| Прийшов `done` | список перемальовується з повного набору: summary, припущення, експорт активний; розгорнуті кейси лишаються розгорнутими |
| `error` або обрив після ≥1 кейса | банер з помилкою, отримані кейси лишаються, позначка «набір неповний», експорт недоступний |
| `error` до першого кейса / 422 | банер з помилкою, повертається попередній результат (або порожній стан) |
| «Зупинити генерацію» | «Генерацію зупинено.», отримані кейси лишаються як неповний набір |

Для ручної перевірки всіх рядків таблиці без API-ключа: `python scripts/fake_stream_server.py <ok|error|early|drop|hang>`.

## Обмеження та рішення
- **Ретраїв немає.** Частину кейсів уже показано, повтор дав би дублікати. У разі збою приходить `error`.
- **Кейси можуть приходити пачками.** API віддає аргументи інструмента шматками різного розміру.
- **Статус 200 навіть у разі помилки.** Заголовки йдуть до першого кадру, тому помилка передається подією.
- **Проксі.** Для nginx виставлено `X-Accel-Buffering: no`; для довгих пауз можна надсилати коментар
  `: ping\n\n` раз на 15 секунд.
- **Скасування.** Якщо клієнт закрив вкладку, генератор переривається, а `async with` закриває потік до Anthropic.
- **`summary` і припущення** приходять лише в `done` (спершу парсер їх не розбирає). Якщо потрібно
  показувати їх раніше, їх теж можна діставати з потоку.
