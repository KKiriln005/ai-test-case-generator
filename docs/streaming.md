# Потоковая генерация (SSE): концепция

## Идея
Claude и так вызывает инструмент `submit_test_suite`; Anthropic API умеет стримить его аргументы
кусками частичного JSON (`content_block_delta` → `input_json_delta`). `CaseExtractor`
(`app/services/stream_parser.py`) собирает эти куски и выдаёт каждый тест-кейс сразу, как только
закрылась его `}`. Кейс валидируется Pydantic, получает серверный ID и уходит клиенту.

```
Claude --partial JSON--> AIService.stream_test_suite --CaseExtractor--> TestCase
        --StreamEvent--> POST /api/generate-stream --SSE--> браузер
```

## Контракт `POST /api/generate-stream`
Тело запроса — то же, что у `/api/generate`. Ответ: `text/event-stream`.

| event   | data                                   | когда                                   |
|---------|----------------------------------------|-----------------------------------------|
| `case`  | один `TestCase` (ID уже `TC-00N`)      | кейс полностью получен и провалидирован |
| `done`  | полный `TestSuite` (summary, допущения)| поток завершён; нужен для экспорта      |
| `error` | `{detail, status}`                     | сбой; после него поток закрывается      |

## Клиент (fetch + ReadableStream)
`EventSource` умеет только GET, поэтому для POST читаем поток вручную:

```js
const r = await fetch('/api/generate-stream', {method: 'POST',
  headers: {'Content-Type': 'application/json'}, body: JSON.stringify(payload)});
const reader = r.body.pipeThrough(new TextDecoderStream()).getReader();
let buf = '';
for (;;) {
  const {value, done} = await reader.read();
  if (done) break;
  buf += value;
  let i;
  while ((i = buf.indexOf('\n\n')) >= 0) {
    const frame = buf.slice(0, i); buf = buf.slice(i + 2);
    const event = /^event: (.*)$/m.exec(frame)?.[1];
    const data = JSON.parse(/^data: (.*)$/m.exec(frame)[1]);
    if (event === 'case') appendCase(data);          // добавить строку в список
    else if (event === 'done') { currentSuite = data; enableExport(); }
    else if (event === 'error') showError(data.detail);
  }
}
```
Это упрощённый пример. Рабочая версия в `app/templates/index.html` дополнительно:
- поддерживает `\r\n`, многострочные `data:` и комментарии `: ping`;
- до начала потока проверяет `response.ok` (ошибки 422/500 приходят обычным JSON);
- считает поток, закрытый без `done` и `error`, обрывом соединения;
- прерывает запрос, если 90 секунд не пришло ни одного байта, и даёт кнопку «Остановить» (`AbortController`).

## Поведение интерфейса

| Ситуация | Что видит пользователь |
|---|---|
| Пришёл `case` | кейс плавно добавляется в конец списка, счётчик «Получено кейсов: N» растёт |
| Идёт генерация | экспорт заблокирован («станет доступен после завершения генерации»), видна кнопка «Остановить» |
| Пришёл `done` | список перерисовывается из полного набора: summary, допущения, экспорт активен; раскрытые кейсы остаются раскрытыми |
| `error` или обрыв после ≥1 кейса | баннер с ошибкой, полученные кейсы остаются, пометка «набор неполный», экспорт недоступен |
| `error` до первого кейса / 422 | баннер с ошибкой, возвращается предыдущий результат (или пустое состояние) |
| «Остановить» | «Генерация остановлена.», полученные кейсы остаются как неполный набор |

Для ручной проверки всех строк таблицы без API-ключа: `python scripts/fake_stream_server.py <ok|error|early|drop|hang>`.

## Ограничения и решения
- **Ретраев нет.** Часть кейсов уже показана, повтор дал бы дубликаты. При сбое приходит `error`.
- **Кейсы могут приходить пачками.** API отдаёт аргументы инструмента кусками разной крупности.
- **Статус 200 даже при ошибке.** Заголовки уходят до первого кадра, поэтому ошибка передаётся событием.
- **Прокси.** Для nginx выставлен `X-Accel-Buffering: no`; для долгих пауз можно слать комментарий
  `: ping\n\n` раз в 15 секунд.
- **Отмена.** Если клиент закрыл вкладку, генератор прерывается, а `async with` закрывает поток к Anthropic.
- **`summary` и допущения** приходят только в `done` (сначала их парсер не разбирает). Если нужно
  показывать их раньше, их тоже можно вынимать из потока.
